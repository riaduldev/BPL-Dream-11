# BPL Dream 11

A responsive BPL Dream 11 player selection web application built with React, TypeScript, and Tailwind CSS.

## 📌 Project Overview

BPL Dream 11 is a fantasy cricket-style web application where users can explore players, select players for their team using available coins, and manage their selected squad.

## ✨ Features

- Responsive modern UI
- Player selection system
- Coin-based player selection
- Add/remove players
- Prevent duplicate selection
- Toast notifications
- Fully responsive design

## 🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- DaisyUI
- React Icons
- React Toastify
